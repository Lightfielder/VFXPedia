# Wishlist/User Interface Improvements/Open File Sketch

On the sketch below you can see the Open File dialog in different modes:

- Gather Sequences = off, Show Missing Files = off - the same as in current version of Fusion.

- Gather Sequences = off, Show Missing Files = on - shows separate files, including files which are missing according to the sequence numbering.

- Gather Sequences = on, Show Missing Files = on - shows continuous parts of the sequence divided by missing files.

- Gather Sequences = on, Show Missing Files = off - similar to the current Gather Sequences mode, but the Type field shows the estimated amount of missing files.
  -- [![Image:OpenFileSketch.gif](images/OpenFileSketch.gif)](index9d64.html?title=File:OpenFileSketch.gif)
  -- The Show Missing Files checkbox could be unchecked by default and the estimation of missing files' names and quantity would begin once it's activated. To refresh the information one could turn it off/on again.
  -- There are also two new options:

- Import a Single file (now implemented as dragging and dropping with Shift)

- Import Only Continuous Part which would be useful if a sequence has been created with gaps for purpose (renderings for different shots to a single sequence or scans containing only needed frames)
