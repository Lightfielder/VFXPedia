# Wishlist/Bins

## Bins

- Bins should save the way content is displayed instead of reverting to the default. It is frustrating to constantly have to reset the way folders and content appears.

- Keep original aspect ratio for thumbnails in bins.

- ability to drag and drop within bins

- ability to scrub and view the thumbnail instead of having the scrubbing view in the view window in fusions' GUI. [similar to the stamp feature but just scrubbing the thumbnail instead]

- Bin shortcuts.  Allow us to create ASCII strings (human readable if possible) that can be used for locating bin items.  Add function to eyeonscript to allow bins to be opened according to the string, and we can open a bin to a specific item from Explorer.
  -- [Chad](indexfe57.html?title=User:Chad)

- Convert to UNC paths.  Add right click menu item or preference to convert local or mapped paths to UNC paths.  When dealing with shared bins, it's important to have UNC paths to allow footage to actually be accessible to other users.
  -- [Chad](indexfe57.html?title=User:Chad)

- Option to store loader in bin as clip, not tool settings. If at all possible including cliplists and with stamp. Nice for organizing already used clips.
  -- [jirka](index91df.html?title=User:Jirka)

- Option to store render in folder highlighted in bin hierarchy. Maybe it already works somehow? There is some suspicious comp preference "SaverBin".
  -- [jirka](index91df.html?title=User:Jirka)
  -- Chad: Like you could drag the SV or LD to a bin and have the option of putting the image there, not the setting?  I would like that.
  -- jirka: Exactly, with option to autocollect renders (savers) to selected bin folder
  -- Daniel: You could try setting the prefs "Comp.Bins.SaverBin" setting to the name of the bin you want the Saver clips to be added to when rendered. Similarly for "Comp.Bins.LoaderBin". It's an experimental feature that was never revealed in the GUI, but it might work well enough for you.
  -- jirka: That is great, thanks!

- Search.  Just need a right click find function that searches by various strings in the .libraries.  As the bins collect footage, it's hard to find a clip.
  -- [Chad](indexfe57.html?title=User:Chad)

- Copy/Paste.  I can drag a clip from one folder to another, but there's no straightforward way to COPY a clip from one folder to another.
  -- [Chad](indexfe57.html?title=User:Chad)
  -- Also, you can't drag from one library to another.  So there isn't a method at all for moving an item from one library to another, so a localhost bin item can't be shared with anyone by moving it to a network bin.
  -- Chad: Today, one of the artists informed me that he had made a folder in the wrong bin.  Just getting the folder moved involved us shutting down the bin server entirely, moving the folder and its entries to the other bin, and restarting the server.  Very messy, and very dangerous.
  -- Chad

- When dragging clip from bins to comp, loader path doesn't convert to Comp: map path. Preference for this will be nice
  -- [Jirka](index91df.html?title=User:Jirka)

- Separate bin to each composition. Those bin must be saved with comp and later opened with comp.
  -- [Chuk](indexa3c8.html?title=User:Chuk&action=edit&redlink=1)

- Stamp folder per Library.  As it currently stands, all stamps are placed in one folder.  I would like to be able to save each library's stamps in their own folder.  So local bins can have local stamps and network bins can have network stamps.
  -- [Chad](indexfe57.html?title=User:Chad)

- If you drag a folder into the bin, it would be nice if it would also add subdirectories too.
  -- [Chad](indexfe57.html?title=User:Chad)

- Add a bin shortcuts to the file browser.  So you can have various bins as favorites, and when you click on them, it opens that bin in the bins floater.
  -- [Chad](indexfe57.html?title=User:Chad)

- Folder watching.  So any clip added to a folder would be added to the bin.
  -- [Chad](indexfe57.html?title=User:Chad)

- IFL / EDL import.  Add clips from some sort of file list (other than the library itself, which is dangerous to edit).
  -- [Chad](indexfe57.html?title=User:Chad)

- Modifier .setting support.  So you can drag a modifier to the bin, save the .setting, then drag from the bin to the input and it adds that modifier (assuming it's the correct type).
  -- [Chad](indexfe57.html?title=User:Chad)
